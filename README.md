# Pulse 메트로놈 & 트랙 메트로놈

브라우저에서 작동하는 고정밀 전자 메트로놈 및 트랙 메트로놈 웹 앱입니다. 별도의 빌드 과정이나 백엔드 서버 없이 브라우저의 Web Audio API 및 Web Speech API로 구동됩니다.

## 주요 기능

### 1. ⏱️ 기본 메트로놈 모드
- **정밀 템포 설정 (BPM 30–400)**: 숫자 직접 입력, 슬라이더 조절, ±1 버튼 조절
- **확장 박자 설정 (2–31박)**: 2/4부터 31/4까지 기본 메트로놈 박자 지정
- **음표 단위 선택**: `2`, `4`, `8`, `16`, `32` 분음표 선택
- **사용자 정의 강박 (Accent)**: 각 마디의 원하는 박자에 강박을 복수로 설정 및 해제
- **정밀 클릭음 합성**: Web Audio API Oscillator + Gain 노드를 이용해 지터(오차) 없는 정확한 클릭음 생성
- **사운드 제어**: 볼륨 조절 슬라이더 및 명확한 소리 켜짐/꺼짐(음소거) 토글
- **탭 템포 (TAP)**: 연타 간격을 실시간 평균 계산하여 즉시 BPM 반영
- **iPhone / iOS 최적화**: Safari 사용자 동작 후 스피커 출력을 위한 오디오 세션 라우팅 적용

### 2. 🎵 트랙 메트로놈 모드 (변속 · 변박 & 가이드 보이스)
- **UI 재배치**:
  - 시작/정지 버튼 아래에 마디 구간(Section) 항목들을 배치하여 조작 편의성 극대화
  - 모바일 한 화면에 핵심 컨트롤이 모두 들어오도록 뷰포트 밀도 최적화
- **영어 가이드 보이스 (여성 음성)**:
  - 구간이 바뀌기 **2마디 전**: 다음 파트 이름을 영어 여성 음성으로 안내 (예: *"Chorus"*, *"Verse"*)
  - 구간이 바뀌기 **1마디 전**: 1부터 박자 끝까지 영어 카운트 출력 (예: *"1, 2, 3, 4"*)
  - 구간별로 가이드 보이스 ON/OFF 독립 설정 가능
- **표준 파트(제목) 선택**:
  - `Ready`, `Intro`, `Verse`, `Pre-Chorus`, `Chorus`, `Interlude`, `Pre-Bridge`, `Bridge`, `Solo`, `Outro`
- **세부 박자 및 음표 단위 설정**:
  - 박자: `2 ~ 31`
  - 음표 단위: `2`, `4`, `8`, `16`, `32`
- **트랙 프리셋 관리**:
  - 트랙 추가 (`+ 새 곡`), 이름 변경 (`✏️`), 복제 (`📋`), 삭제 (`🗑️`)
  - `Mrs Green Apple - A Posteriori`, `Mrs Green Apple - StaRt` 등 변속·변박 정밀 프리셋 기본 탑재
  - 로컬 스토리지 영구 저장으로 브라우저 재접속 시에도 트랙 목록 유지
- **실시간 모니터링 & 내비게이션**:
  - 현재 구간명, 구간 내 마디 진행 (`2 / 4`), 전체 트랙 마디 진행 (`14 / 28`) 실시간 시각화
  - `전체 마디` 버튼으로 원하는 전체 마디 번호를 입력하여 즉시 이동 가능
  - 구간 클릭 시 해당 마디로 즉시 이동 (Seek), `⏮ 처음부터` 되감기, `🔁 전곡 반복`

### 3. ⚙️ 옵션 메뉴
우측 상단의 정사각형 옵션 버튼에서 설정합니다.

- **보이스 가이드 볼륨 조절**:
  - `0%`부터 `100%`까지 트랙 메트로놈의 파트명 및 카운트 음성 볼륨을 조절할 수 있습니다.
- **악센트 표시방법**:
  - `전체화면`: 강박에서 화면 전체가 반짝입니다.
  - `부분화면`: 기본 상태처럼 박자 원형 영역만 반짝입니다.
  - `끄기`: 반짝이는 시각 효과를 끕니다.
- **로그 제출하기**:
  - 버튼을 누른 시점 기준 최근 1분간의 동작 로그를 클립보드에 복사합니다.
