# Pulse 메트로놈 & 곡별 마디 시퀀서

브라우저에서 작동하는 고정밀 전자 메트로놈 및 곡별 마디 시퀀서 웹 앱입니다. 별도의 빌드 과정이나 백엔드 서버 없이 브라우저의 Web Audio API로 구동됩니다.

## 주요 기능

### 1. ⏱️ 기본 메트로놈 모드
- **정밀 템포 설정 (BPM 40–240)**: 숫자 직접 입력, 슬라이더 조절, ±1 버튼 조절
- **박자 및 분모 설정**: 2/4, 3/4, 4/4, 5/4, 6/8, 7/8, 8/8 등 다양한 박자 지원
- **사용자 정의 강박 (Accent)**: 각 마디의 원하는 박자에 강박을 복수로 설정 및 해제
- **정밀 클릭음 합성**: Web Audio API Oscillator + Gain 노드를 이용해 지터(오차) 없는 정확한 클릭음 생성
- **사운드 제어**: 볼륨 조절 슬라이더 및 명확한 소리 켜짐/꺼짐(음소거) 토글
- **탭 템포 (TAP)**: 연타 간격을 실시간 평균 계산하여 즉시 BPM 반영
- **iPhone / iOS 최적화**: Safari 무음 모드에서도 스피커 출력이 유지되도록 오디오 세션 라우팅 적용

### 2. 🎵 곡별 프리셋 & 마디 시퀀서 모드 (변속 · 변박)
- **곡별 프리셋 관리**:
  - 곡 프리셋 추가 (`+ 새 곡`), 이름 변경 (`✏️`), 복제 (`📋`), 삭제 (`🗑️`)
  - 로컬 스토리지 영구 저장으로 브라우저 재접속 시에도 곡 목록 유지
- **마디 단위 변속 (Tempo Change)**:
  - 인트로(100 BPM) → 절(120 BPM) → 후렴(144 BPM) 등 마디 구간마다 서로 다른 템포 자동 전환
- **마디 단위 변박 (Meter Change)**:
  - 4/4박 곡 중간에 3/4박 브릿지나 2/4박 변박 마디 삽입 가능
- **구간 세부 설정**:
  - 구간 이름 (Intro, Verse, Chorus, Outro 등), 마디 수 (1~999), 템포(BPM), 박자, 구간별 강박
  - 구간 순서 변경 (`▲`, `▼`), 세부 편집 (`✏️`), 삭제 (`🗑️`)
- **실시간 마디 추적 및 모니터링**:
  - 현재 구간명, 구간 내 마디 진행 (`2 / 4 마디`), 전체 곡 마디 진행 (`14 / 28 마디`) 실시간 시각화
  - 구간 목록에서 원하는 마디를 클릭하면 해당 위치로 즉시 이동 (Seek)
  - `⏮ 처음부터`: 1마디로 즉시 되감기
  - `🔁 전곡 반복`: 곡 종료 후 처음부터 무한 반복 또는 1회 완주 후 정지 선택
